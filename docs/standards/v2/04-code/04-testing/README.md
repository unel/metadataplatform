# 04-code/04-testing: Финальный прогон тестов (Green)

## Что делает

Запускает полный тест-suite после завершения code-review (когда замечания исправлены). Это TDD Green шаг: все тесты должны пройти. Отличается от `03-tests/04-run` тем, что здесь реализация уже написана и отревьюена.

## Входящие артефакты

- `04-code/02-review/report-NNN.md` со статусом `done` (нет critical/warning)
- Код реализации (финальная версия после фиксов)
- Тесты в `tests/happy/` и `tests/adversarial/`

## Исходящие артефакты

- `04-code/04-testing/report-NNN.md` — результаты прогона

## Артефакты процесса

- `base-plan.md` — инструкции
- `base-checklist.md` — чек-лист
- `report-NNN.md` — результат прогона (иммутабельный)
