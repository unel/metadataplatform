# Каталог этапов и шагов workflow v2

Структура задачи: `tasks/NNNN-<slug>/stages/<NN-этап>/<NN-шаг>/`

Полное описание структуры шага, статус-лога и репорта — в `docs/standards/v2/stages-standard.md`.

---

## Пример флоу (happy path)

Конкретный флоу определяется оркестратором задачи — какие этапы включены и в каком порядке.
Fix-шаги (`03-fix`, `04-fix` и т.д.) запускаются по необходимости после failed-ревью — здесь не показаны.

```
00-research
  → 01-spec/01-write → 01-spec/02-review
  → 02-acceptance/01-write → 02-acceptance/02-review
  → 03-tests/01-write → 03-tests/02-review → 03-tests/04-run
  → 04-code/01-write → 04-code/02-review → 04-code/04-testing
  → 05-docs/01-write → 05-docs/02-review
  → 06-retro
```

`stale` распространяется вниз по цепочке при изменении вышестоящего артефакта.
