# Action: auto-proceed при failed → fix

## Проблема

Оркестратор останавливался после каждого failed и ждал подтверждения — даже когда следующий шаг (fix) очевиден. Лишние паузы замедляют флоу и раздражают.

## Решение

Если review вернул `failed` и следующий шаг однозначен (fix) — оркестратор запускает fix автоматически без паузы. Останавливаться только если нужно решение пользователя (3+ итераций, clarification, неожиданная ситуация).

## Шаги

- [ ] Обновить base-plan оркестратора: "failed → fix без паузы если следующий шаг однозначен"
