# Action: compact summary-артефакт состояния фичи

## Проблема

Контекст жрётся по кругу: одни и те же файлы читаются снова и снова. Нет компактного summary состояния фичи — оркестратор читает все status-log по отдельности при каждом восстановлении.

## Решение

`tasks/<feature>/STATUS.md` — один файл с текущим состоянием фичи:
- последний статус каждого шага
- ключевые решения
- открытые вопросы

Обновляется `scripts/feature-status.sh --update`. Читается вместо всех status-log при восстановлении контекста.

- [ ] Определить формат STATUS.md
- [ ] Добавить в `scripts/feature-status.sh` флаг `--update` для генерации
