# Action: раздел "Error types" в шаблоне spec

## Проблема

Sentinel errors появились на этапе code-fix, не до написания кода. Router сначала сравнивал ошибки строками, переделывали. Интерфейсы определяются отдельно от типов ошибок — нет правила "ошибки сначала".

## Решение

В шаблон spec добавить раздел:

```markdown
## Типы ошибок

- `ErrNotFound` — сущность не найдена
- `ErrInvalidID` — невалидный идентификатор
- `ErrAlreadyExists` — сущность уже существует
- ...

Реализация: sentinel errors в отдельном файле `errors.go` до написания основного кода.
```

- [ ] Добавить пункт в `docs/standards/v2/04-code/01-write/base-plan.md`: "Написать errors.go первым"
