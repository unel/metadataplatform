# Action: gate перед запуском 06-retro

## Проблема

05-docs/02-review имел статус failed. Ретро запущено без явного решения о пропуске — нигде не задокументировано. Выглядит как забыли, а не как сознательное решение.

## Решение

Перед запуском `06-retro/01-recall` оркестратор проверяет: все шаги 00–05 в `done`. Если нет — два варианта:
1. Стоп: показать список незакрытых шагов, ждать инструкций пользователя
2. Явное решение пользователя "идём дальше несмотря на X" — документируется в `06-retro/01-recall/status-log.md`
