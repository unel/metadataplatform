# Action: RFC — Танк и Бо без Write tools

## Проблема

Танк и Бо не имеют Write/Edit tools. Оркестратор получает контент от агента и сам записывает файлы вручную — медленно, с риском пропустить опечатки. Это стабильная процедура, но ощущается как обход ограничения, а не нормальная работа.

## Решение

RFC: два варианта для обсуждения:
1. **Добавить Write tool** в конфиг Танка и Бо — они пишут артефакты сами
2. **Задокументировать как намеренный дизайн** — оркестратор отвечает за запись всех артефактов; агенты возвращают контент

## Шаги

- [ ] Изучить возможность добавить Write tool в конфиг субагентов
- [ ] Принять решение и задокументировать в `docs/standards/v2/` или CLAUDE.md
