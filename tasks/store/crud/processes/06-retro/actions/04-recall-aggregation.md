# Action: 01-recall агрегирует notes/complaints из всех папок процессов

## Проблема

`06-retro/01-recall` собирал только файлы которые уже лежали в своей директории. `complaints-user.md` из `00-research/01-interview/`, `00-research/02-web/`, `01-spec/02-review/` — всё пропустил. `notes-азирафаль.md` из `03-tests/01-write/` — тоже. В ретро попали только данные из recall-директории.

## Решение

В начале скилла `01-recall` добавить шаг агрегации:

```bash
find tasks/<feature>/processes/ \
  -name "notes-*.md" -o -name "complaints-*.md" \
  | grep -v "06-retro/01-recall"
```

Найденные файлы — копировать/агрегировать в `06-retro/01-recall/` с пометкой источника. Дедуплицировать по имени участника (если файл уже есть — дополнить, не перезаписывать).
