# Action: gate-блокировка pipeline — вышестоящие шаги не в pending

## Проблема

spec-ft, spec-nft, spec-review остались в pending. Code, code-review помечены done. Оркестратор не проверял статус вышестоящих шагов перед запуском следующего. Итог: код написан и отревьюен без контракта.

## Решение

В оркестраторе (feature/v2:feature) перед запуском каждого шага: проверять что все вышестоящие шаги имеют статус `done` в status-log.md. Если нет — стоп, сообщить пользователю, ждать инструкций.

Цепочка зависимостей:
```
00-research → 01-spec → 02-acceptance → 03-tests → 04-code → 05-docs → 06-retro
```
Внутри группы: write → review → fix → (run/testing).

## Шаги

- [ ] Добавить проверку в `docs/standards/v2/feature/base-plan.md` — раздел "Точка входа"
- [ ] Задокументировать в CLAUDE.md: "оркестратор не двигается если вышестоящий шаг в pending"
