# Action: стандарт start/end в status-log.md

## Проблема

Агенты записывают только итоговый статус. Нельзя понять сколько шаг занял времени, завис ли он, или завершился нормально.

## Решение

Стандарт двух записей на каждый запуск шага:

```markdown
# 2026-05-05T14:00:00Z — in-progress
Начало работы. <опциональный контекст>

# 2026-05-05T14:23:11Z — done (run 1)
<итог>
```

`scripts/log-note.sh` и `feature-status.sh` поддерживают этот формат.

## Шаги

- [ ] Задокументировать стандарт в `docs/standards/v2/` (общий для всех шагов)
- [ ] Обновить base-plan.md в каждом скилле — добавить запись `in-progress` в начале
- [ ] Обновить `scripts/feature-status.sh` — показывать время выполнения если есть start+end
