# Action: пункт "инварианты валидации" в шаблоне acceptance

## Проблема

CRITICAL-1 (path traversal): инвариант "id используется как имя файла → id не может содержать `../` или `/`" нигде не был записан. Ада строила путь через `filepath.Join(dir, id+".json")` не задав себе вопроса. Рецидив из store/connection: CR-7 → deadlock — инвариант тоже не был задокументирован.

## Решение

В шаблоне acceptance для операций с пользовательскими данными (id, path, user input) — обязательный пункт:

```markdown
## Инварианты валидации

Для каждого входного параметра который используется как:
- имя файла / компонент пути → запрещены: `../`, `/`, нулевой байт
- ключ в хранилище → запрещены: пустая строка, спецсимволы
- ...

Нарушение инварианта → конкретная ошибка (указать sentinel error).
```
