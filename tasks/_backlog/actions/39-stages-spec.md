# Action: каталог этапов и шагов workflow v2

## Проблема

Спецификация этапов и шагов не существует как единый документ.
Что есть сейчас: скиллы (`.claude/commands/`), CLAUDE.md с высокоуровневым описанием.
Агент не может прочитать одно место и понять полный список этапов, шагов, их назначение и порядок.

## Решение

`docs/standards/v2/stages.md` — каталог:
- Все этапы (00-research, 01-spec, 02-acceptance, 03-tests, 04-code, 05-docs, 06-retro)
- Шаги внутри каждого этапа (write, review, fix, run, testing…)
- Назначение каждого шага, входные и выходные артефакты
- Порядок и зависимости (каскадный сброс)
- Исполнитель по умолчанию (какой агент)
