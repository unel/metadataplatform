# Action: флоу для задач не привязанных к фиче

## Проблема

Текущий workflow (v2) рассчитан на фичи: spec → acceptance → tests → code → docs → retro.
Часть задач не вписывается: обновление Go, рефакторинг структуры проекта, инфраструктурные изменения.
Для них нет ни процессного шаблона, ни понятного места в tasks/.

## Решение (нужно продумать)

Варианты:
- Упрощённый workflow: только нужные фазы (напр. spec + code + retro без acceptance/tests)
- Отдельный тип задачи "infrastructure" с другим набором шагов
- tasks/_backlog/ как временное место до оформления в фичу
