# Action: авторство в начале Go-файлов и тестов

## Проблема

Непонятно кто создавал и дополнял конкретный файл. `git blame` показывает оператора (unel), а не агента — Кроули, Азирафаль, Ада. Исторический контекст теряется.

## Решение

Добавить комментарий-заголовок в начало файлов, создаваемых агентами:

```go
// Authors: Кроули (adversarial tests), Азирафаль (happy tests)
```

Или в формате contribution log:
```go
// Created: Азирафаль (03-tests/01-write, 2026-04-29)
// Updated: Азирафаль (03-tests/03-fix, 2026-04-30)
```

## Вопросы для проработки

- Формат: однострочный или многострочный?
- Что именно фиксируем: агент, этап, дата?
- Применять к Go-файлам кода тоже, или только к тестам?
- Ретроспективно применить к существующим файлам?
