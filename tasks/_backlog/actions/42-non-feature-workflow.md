## Проблема

Часть задач не вписывается в стандартный v2 флоу (spec → acceptance → tests → code → docs → retro): обновление Go, рефакторинг структуры проекта, инфраструктурные изменения, написание скриптов.
Для них нет ни флоу-шаблона, ни понятного места в tasks/.

## Решение (нужно продумать)

- Определить флоу для "infrastructure" / "tooling" задач (какие этапы нужны, какие нет)
- Подумать какие ещё флоу могут быть нужны помимо стандартного feature-флоу и non-feature
- Возможно: упрощённый флоу только из нужных фаз (напр. spec + code + retro)
- Возможно: отдельный тип "infrastructure" с другим набором шагов
