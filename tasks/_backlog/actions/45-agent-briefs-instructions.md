# Action: инструкции агентам про брифы

## Проблема

Агенты не знают что перед вызовом `begin-step.sh` нужно создать `brief-NNN.md` — вводную для текущего рана. Без этого `begin-step` упадёт с ошибкой.

## Решение

Дописать в AGENT.md каждого агента (или в общий шаблон write-скиллов) раздел о том, что:
- Перед стартом работы агент создаёт `brief-NNN.md` (где N = текущий run + 1)
- В brief: что делаем, входные данные, ссылки на upstream-артефакты
- После создания brief — вызывает `begin-step.sh`
- Аналогично: перед `end-step.sh` — создать `report-NNN.md`
