# Action: оркестратор передаёт список файлов ревьюеру

## Проблема

У ревьюера нет shell. Поиск нужных файлов в untracked директориях — угадывание имён через несколько попыток. Гримм тратил попытки на ls вместо ревью.

## Решение

Оркестратор перед запуском ревью-скилла: собирает список релевантных файлов и передаёт явно в промпте:
```
Файлы для ревью:
- tasks/0002-store-crud/stages/01-spec/01-write/report-001.md
- tasks/0002-store-crud/spec.md
```
