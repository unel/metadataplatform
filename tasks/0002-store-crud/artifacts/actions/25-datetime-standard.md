# Action: стандарт передачи datetime через date -u

## Проблема

Агенты пишут время приблизительно вручную (15:00:00Z вместо реального 14:59:25Z) — угадывают вместо получения реального UTC. Это уже задокументировано в memory оркестратора, но не в стандартах проекта.

## Решение

Задокументировать в `docs/standards/v2/` и CLAUDE.md:
> Оркестратор передаёт `$(date -u +"%Y-%m-%dT%H:%M:%SZ")` в промпт каждого субагента. Субагенты не угадывают время.
