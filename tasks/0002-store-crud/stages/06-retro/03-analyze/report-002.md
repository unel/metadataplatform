## Группировка проблем

### Требования

- **API-контракт до test-write** — Азирафаль, Кроули, Гримм, Харли
  AC не содержит сигнатур конструкторов/интерфейсов/логгеров. Два тест-агента угадывали независимо → несовместимые типы → 4+ лишних раунда. `*fs.Store` с тремя `Get`-методами — невозможно в Go, нашла Ада в 04-code.

- **Спека Go-specific без разделения контракт/реализация** — Танк, Ада, Кроули, пользователь
  `filepath.Join`, `named return`, конкретные сигнатуры смешаны с требованиями. CR-15 предписал паттерн без полного инварианта → CRITICAL-1 в code-review. 5 итераций / 21 замечание — часть из них к стилю/Go, не к требованиям.
  _Root cause:_ шаблон spec не имеет разделов "Контракт" и "Реализация на Go".

- **Инварианты не документируются** — Ада, Гримм
  Path traversal: инвариант "id используется как имя файла → id не может содержать `../`" не записан нигде. Ада строила путь, не спросив себя этого. Рецидив из store/connection (CR-7 → deadlock — тот же паттерн).
  _Root cause:_ нет обязательного пункта "инварианты валидации" в шаблоне AC для операций с пользовательскими данными.

- **Sentinel errors не определяются до реализации** — Ада
  Типы ошибок появились на этапе fix, не до написания кода. Router сначала сравнивал строками, переделывали. Интерфейсы определяются отдельно от типов ошибок, и нет правила "ошибки сначала".
  _Root cause:_ отсутствует шаг/пункт в шаблоне который требует определить error types до code-write.

- **Go-стандарты не подключаются к ревью** — пользователь
  `docs/standards/v2/extensions/` не существует. Гримм написал "расширения: нет" при том что `docs/standards/go/` содержит принципы concurrency, error-handling, interfaces, testing, project-structure — прямо релевантные.
  _Root cause:_ скиллы ссылаются на несуществующую директорию; пути к Go-стандартам не передаются явно в промпты ревью.

- **Спека drift — две копии без явной актуальной** — пользователь
  Полный текст спеки в `01-spec/01-write/report-001.md` и в `01-spec/03-fix/report-NNN.md`. Агенты читают разные версии, неизвестно какая актуальна.
