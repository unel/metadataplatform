# complaints-user

[инициализация] Подозрение что datetime пишется в UTC-формате но с локальным временем. Проверено: сервер в UTC (+0000), фактического расхождения нет. Но Танк пишет время приблизительно вручную (15:00:00Z вместо реального 14:59:25Z), не через `date -u`. Нужно чтобы агенты всегда получали datetime через `date -u`, не угадывали.
